# FedFlow / FCHA paper: Springer Nature version

Built with the official Springer Nature LaTeX template (`sn-jnl.cls`, numbered reference style
`sn-mathphys-num`). Compiled PDF: `FedFlow_FCHA_Springer.pdf`.

## Compile

- Overleaf: upload `fedflow_springer_overleaf.zip` (New Project → Upload Project). Overleaf runs BibTeX itself.
- Locally: `C:\Users\musun\tools\tectonic\tectonic.exe -X compile main.tex`.

## Files

- `main.tex`: the paper. `refs.bib`: 34 references. `figures/`: generated by `../fedflow_paper/make_figures.py`.
- Numbers in the text and tables come from `paper_results/REPORT.md` and `RESULTS.md`.

## References

Each entry was checked against the paper's PDF (in `papers/`) or the publisher/DBLP record.
Fields that could not be confirmed were left out instead of guessed: no volume/pages for Chang &
Branco (Applied Intelligence 2024), Campos et al. (Computer Networks 2022), Li et al. (ICDE 2022)
and Cui et al. (CVPR 2019); their DOIs or venues are given. The base paper is FedGATSage
(Al Tfaily et al., Scientific Reports 2025), the same file as `Downloads/accuracylespaper.pdf`.

## Before submission

1. Fill in authors, affiliations, e-mails, acknowledgements, funding, author contributions and
   the repository URL (search for `[` in `main.tex`).
2. Fill in the "Use of AI tools" declaration according to the target journal's policy.
3. Run the journal's similarity check (iThenticate/Turnitin). The text is written from scratch and
   quotes no source, but only the official check gives a number.
4. Check the target journal's author instructions (abstract length, reference style option).
